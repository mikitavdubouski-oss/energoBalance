# ЭнергоБаланс: Стратегия экономии — контекст проекта

Этот файл — постоянный контекст для Claude. Читай его перед любой задачей в проекте.

## Что делаем

Образовательная браузерная игра для республиканского конкурса «Энергомарафон» (XX конкурс, 2026/2027),
номинация «Геймификация в энергосбережении», подноминация «Компьютерная игра».
Срок сдачи финальной сборки — до 20 декабря 2026.

- **Аудитория:** учащиеся 7–11 классов (12–17 лет), Беларусь. Без технической подготовки.
- **Жанр:** 2D point-and-click квест + симулятор управления ресурсами + мини-игры.
- **Роль игрока:** «Энергоменеджер» — школьник, который проводит энергоаудит.
- **Локации (уровни):**
  1. Квартира — лампы, standby-режим, бытовые приборы, вода, отопление.
  2. Школа — класс, коридор, столовая: освещение, отопление, водоснабжение.
  3. Мини-город — уличное освещение, ВИЭ (солнце, ветер), отходы как ресурс.

## Ключевые механики

- **Три шкалы:** «Потребление» (снижать), «Бюджет» (условные единицы, не уйти в минус), «Комфорт» (не уронить).
- **Аудит (режим детектива):** на сцене есть «проблемные зоны» (hotspots). Клик → меню из 2–4 действий
  (выключить / заменить / утеплить / оставить как есть). Правильное действие улучшает шкалы, неправильное штрафует.
- **Триггеры:** пока проблема не решена, она «тикает» — например, открытый кран каждые N секунд
  увеличивает счётчик воды и уменьшает бюджет.
- **Рандомизация:** при старте уровня часть проблем выбирается случайно из пула, чтобы не заучивали расположение.
- **Мини-игры:** термостат (квартира), сортировка отходов (школа), сборка солнечной панели (город).
- **Итог уровня:** Score = (сэкономленная энергия × коэфф. сложности) + бонус за комфорт − штраф за ошибки.
  Плюс «Эко-коины» и персональная обратная связь («Ты сэкономил 15%, но снизил комфорт…»).
- **Без запретительного дидактизма:** игра учит *оптимизировать*, а не запрещать
  (стиральная машина с полной загрузкой — правильно; «никогда не стирать» — неправильно).

## Технологии (жёсткие ограничения)

- **Чистый HTML5 + CSS + JavaScript (ES2017+), без движков, фреймворков и сборщиков.**
- **Игра должна запускаться двойным кликом по `index.html` (протокол `file://`) без интернета и без сервера.** Поэтому:
  - НЕ использовать ES-модули (`import/export`) — в Chrome они не работают через `file://`.
    Подключать скрипты обычными `<script src>` в нужном порядке, всё в одном глобальном пространстве имён `window.EB`.
  - НЕ использовать `fetch` / XHR для загрузки данных. Все данные (уровни, тексты, факты) — в `.js`-файлах как объекты.
  - Никаких CDN, внешних шрифтов и ссылок в сеть. Шрифт — системный стек.
- **Графика:** векторная, SVG (inline или файлы в `assets/svg`), мультяшный стиль, стилизованные подростки.
  Сцены масштабируются под экран через `viewBox`.
- **Звук:** звуковые эффекты синтезируются через Web Audio API (без файлов) или лежат в `assets/audio` как `.mp3/.ogg`.
  Голос «Советника» — `speechSynthesis` браузера (если доступен) + опционально записанные `.mp3`.
- **Сохранение:** `localStorage` (обёрнуто в try/catch, игра должна работать и без него).
- **Целевые экраны:** от 1366×768 до интерактивных панелей; управление мышью и касанием (pointer events).
- **Производительность:** первый уровень загружается за 1–2 секунды, общий размер сборки — в пределах нескольких МБ.

## Принятые решения (не менять без обсуждения)

- **SVG-сцены лежат в `js/scenes/*.scene.js` строками**, а не файлами в `assets/svg`: через `file://`
  код не может менять внешний SVG. Контракт сцены (группы `obj-*`, `.v-problem` / `.v-ok`, `.obj-hit`) — в `assets/README.md`.
- **Логика уровня одна на все уровни** (`js/core/game.js`); уровни и проблемы — только данные.
- **Тексты проблем** — в `texts.*.js` по ключам `hs.<id>.*`; перевод фактов — `fact.<id>` в `texts.be.js`.
- **Факты с [ПРОВЕРИТЬ] скрыты от игроков**, пока `config.hideUnverifiedFacts = true`.
- **Отладка не удаляется, а выключается** флагом `config.debug = false`.
- **Счётчики кВт·ч / л / Гкал — условные игровые единицы**, это сказано в записке.
- Ассеты (звуки, музыка, голос, значки сортировки) — заглушки-синтез; замена файлами без правки логики.
  Голос Советника уже записан (assets/audio/voice, voiceFiles: true).
- **Каждое открытие игры — новый игрок:** эко-коины, звёзды и открытые уровни обнуляются, рекорды уровней и настройки
  сохраняются (save.js → newSession). За уровень в зачёт идёт лучший результат сессии — переигрыванием монеты не накрутить.
- **Финал:** медаль по эко-коинам — 1, 2 или 3 место (пороги medals в config.js) с похвалой; плюс звание по звёздам.
- **Сортировка отходов:** 3 уровня сложности на выбор, на лёгком очков меньше (множитель points).
- **Телефон вертикально:** в игре показывается «Поверни телефон» и ставится пауза; меню и итоги работают и вертикально.

## Правила кода

- **Комментарии — на русском**, понятные школьнику из кружка информатики. Каждый файл начинается с шапки:
  что делает файл и как его менять.
- Все «магические числа» баланса — только в `config.js`. Все тексты интерфейса — только в `texts.*.js`.
- Новый hotspot / факт / уровень добавляется правкой данных, а не логики.
- Простые функции и понятные имена важнее «умных» абстракций.
- Никаких внешних зависимостей. Если очень нужна библиотека — сначала спроси.

## Дизайн и доступность

- Яркая, дружелюбная палитра. Крупные элементы (кнопки не меньше 48×48 px), читаемый текст (не меньше 18 px).
- **Дальтонизм:** не передавать смысл только красным/зелёным. Шкалы и статусы дублировать иконкой, формой или подписью.
  Не ставить красный/зелёный текст на тёмный фон.
- Стартовое меню: место под логотип «Энергомарафона» (`assets/logo/`), пока заглушка.
- Контент безопасен: без насилия, грубости и политики.

## Образовательный контент

- Охватить: электроэнергию, тепловую энергию, воду, отходы как ресурс.
- Факты — с белорусским контекстом (тарифы, программы замены освещения, энергоёмкие приборы).
- **Не выдумывать цифры.** Если точного значения нет, ставить метку `[ПРОВЕРИТЬ]` и поле `source` с пустой строкой.
  Всё помеченное соберём в список и проверим по официальным источникам (Департамент по энергоэффективности
  Госстандарта РБ, energoeffekt.gov.by, Минэнерго РБ).

## Меню и экраны

Главное меню: Играть · Продолжить (если в этот раз уже пройден уровень) · Настройки (звук, музыка, голос, язык) · Об игре (титры: учащиеся и педагог, источники).
Кнопки «Выход» нет (решение 12.11.2026): браузер не даёт игре закрыть вкладку.
В игре: HUD со шкалами, пауза, перезапуск уровня, подсказка (ограниченное количество на уровень).
Автосохранение при переходе между уровнями.
