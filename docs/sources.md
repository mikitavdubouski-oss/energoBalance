# Источники информации

Список дополняется по мере проверки фактов (см. `docs/facts-to-verify.md`).
Для каждого проверенного факта впишите ссылку или выходные данные документа и дату обращения
также в поле `source` в `js/data/facts.js`.

## Основные источники для проверки

1. Департамент по энергоэффективности Государственного комитета по стандартизации Республики Беларусь — https://energoeffekt.gov.by
2. Министерство энергетики Республики Беларусь — https://minenergo.gov.by
3. Министерство природных ресурсов и охраны окружающей среды Республики Беларусь — https://minpriroda.gov.by
4. ГУ «Оператор вторичных материальных ресурсов» — сайт организации (уточнить адрес)
5. РУП «Белорусская атомная электростанция» — сайт организации (уточнить адрес)
