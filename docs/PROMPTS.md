# Промпты для разработки «ЭнергоБаланс»

Как пользоваться:

1. Папка проекта (сейчас `energo Tat`) содержит в корне `CLAUDE.md`. Claude читает его автоматически.
2. Открой папку в VS Code и запусти расширение Claude.
3. Отправляй промпты **по одному, по порядку**. После каждого открой `index.html` в браузере и проверь результат.
   Только после этого переходи к следующему.
4. Если что-то сломалось, опиши, что видишь, и приложи текст ошибки из консоли браузера (F12 → Console).

Отметки: ☐ → ☑, когда этап готов.

> **Статус на 11.11.2026:** этапы 0–8 выполнены (код, графика, звук, перевод, документы).
> Не выполнены: точка проверки с учениками после этапа 3 и этап 9 (проверка фактов, перевода,
> заполнение заглушек, ручное тестирование). Что где лежит и что ждёт решения — в **[PROJECT-MAP.md](../PROJECT-MAP.md)**.

## Этап 1. Ядро игры

### ☑ 1.1 Состояние и шкалы

```
Реализуй js/core/config.js и js/core/state.js.
Состояние: текущий уровень, шкалы consumption / budget / comfort (0–100), счётчики электроэнергии (кВт·ч),
тепла (Гкал), воды (л), эко-коины, ошибки, оставшиеся подсказки, список решённых hotspot'ов.
Все стартовые значения и пределы — в config.js. Изменять состояние только через функции
(EB.state.change('comfort', -5, reason)), которые генерируют событие 'state:changed'.
```

### ☑ 1.2 Шина событий и триггеры

```
Реализуй js/core/events.js:
- on / off / emit;
- система «тикающих» триггеров: EB.triggers.add(id, {everyMs, effect}) — каждые everyMs мс применяет effect
  к состоянию, пока триггер не удалён. Пример: открытый кран каждые 2 с даёт +1 л воды и −1 к бюджету;
- триггеры ставятся на паузу вместе с игрой.
Добавь в консоль отладочную команду EB.debug.state() для просмотра состояния.
```

### ☑ 1.3 Сохранение

```
Реализуй js/core/save.js: автосохранение в localStorage при завершении уровня и при смене настроек.
Сохраняем прогресс (открытые уровни, лучшие очки, эко-коины) и настройки (звук, музыка, голос, язык).
Всё обернуть в try/catch: если localStorage недоступен, игра работает без сохранения и не падает.
В главном меню: если есть сохранение — кнопка «Продолжить»; в настройках — «Сбросить прогресс» с подтверждением.
```

## Этап 3. Уровень 1 — Квартира (прототип)

### ☑ 3.1 Сцена квартиры

```
Нарисуй SVG-сцену квартиры в мультяшном стиле (viewBox 1600×900): гостиная + кухня + ванная,
окно с дневным светом. Объекты: люстра, торшер, телевизор, компьютер, зарядка в розетке, холодильник,
стиральная машина, чайник, кран на кухне, кран в ванной, батарея, окно (щель), бойлер.
Каждый интерактивный объект — отдельная группа <g id="..."> с двумя состояниями (проблема / решено),
чтобы можно было переключать вид из кода. Сцена масштабируется под экран без искажений.
```

### ☑ 3.2 Данные hotspot'ов и аудит

```
Создай js/data/hotspots.js с пулом проблем для квартиры (10–12 штук). У каждой:
id, объект в сцене, ресурс (электричество / тепло / вода), описание проблемы,
2–4 действия {текст, правильное?, эффект на шкалы, пояснение}, тикающий эффект, пока проблема не решена.
Пример: «Свет горит днём» → [Выключить ✔] [Заменить на LED ✔ (дороже, но выгоднее надолго)] [Оставить ✘].
Действия не должны быть запретительными: учим оптимизировать (полная загрузка стиралки, режим эко и т.п.).

Реализуй js/levels/apartment.js:
- при старте случайно выбирается 6–8 проблем из пула (параметр в config.js);
- клик/тап по объекту → всплывающая карточка с действиями;
- выбор действия меняет шкалы, проигрывает короткую анимацию, показывает пояснение в 1–2 предложения;
- уровень заканчивается, когда решены все проблемы или вышел таймер (время в config.js).
```

### ☑ 3.3 Подсчёт очков и экран итогов

```
Реализуй js/core/scoring.js:
Score = (сэкономленная энергия × коэфф. сложности) + бонус за комфорт − штраф за ошибки.
Коэффициенты — в config.js. Эко-коины = Score / N.
Экран итогов: очки, звёзды (1–3), эко-коины, процент экономии по каждому ресурсу,
2–3 персональных совета по ошибкам игрока, например: «Ты сэкономил 15% электроэнергии, но снизил комфорт.
Попробуй энергосберегающую лампу вместо того, чтобы выключать весь свет».
Кнопки: Переиграть / Следующий уровень / Меню.
```

### ☑ 3.4 Факты между уровнями

```
Создай js/data/facts.js — 25–30 коротких фактов по энергосбережению с белорусским контекстом:
LED vs лампа накаливания, standby-потребление, самые энергоёмкие бытовые приборы,
вода и тепло в многоквартирном доме, сортировка отходов, ВИЭ в Беларуси.
Формат: {id, text, resource, source}. НЕ выдумывай цифры: где не уверен, ставь [ПРОВЕРИТЬ] и пустой source.
Показывай случайный факт на экране загрузки уровня и после экрана итогов.
В конце выведи список всех фактов с меткой [ПРОВЕРИТЬ].
```

```

- раздельная громкость эффектов и музыки из настроек;
- звук стартует только после первого действия пользователя (ограничение браузеров).

```
