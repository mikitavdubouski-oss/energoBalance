# Реплики Советника — список для озвучки

Каждая реплика — отдельный файл. Имя файла = id реплики + `.mp3`.

- Русские файлы: `assets/audio/voice/<id>.mp3` (например, `assets/audio/voice/advisor.firstCorrect.mp3`).
- Белорусские файлы: `assets/audio/voice/be/<id>.mp3`.
- После записи включите в `js/core/config.js`: `voiceFiles: true`. Если какого-то файла нет, игра прочитает реплику синтезатором речи.
- {n} в тексте — число проблем на уровне. При записи скажите фразу без числа или замените на «несколько».
- Совет по записи: mp3, моно, 44,1 кГц, 96–128 кбит/с, без тишины в начале и конце, спокойный дружелюбный голос подростка.

Список сгенерирован из js/data/texts.ru.js и texts.be.js. Если меняете текст реплики там — обновите и запись.
