# Скриншоты и трейлер (этап 8.3)

## Как снимать

- Окно браузера 1920×1080 (F11 — полноэкранный режим), масштаб 100%.
- Для автоматического показа: дважды щёлкните `demo.html` (это ярлык на `index.html?demo=1`, квартира),
  или откройте в адресной строке `index.html?demo=1&level=school`
  или `index.html?demo=1&level=city`. Игра сама решит 3 проблемы с паузами — удобно для записи видео.
  Прогресс игрока в демо-режиме не сохраняется. В правом нижнем углу — маленькая надпись «Демо-режим»;
  при монтаже её можно обрезать.
- Количество и темп действий демо — `demo.solveCount` и `demo.stepMs` в `js/core/config.js`.
- Запись экрана: Win + G (Xbox Game Bar) или OBS Studio.

## Ключевые кадры для скриншотов (8 штук)

| № | Кадр | Как получить |
|---|---|---|
| 1 | Главное меню с логотипом «Энергомарафона» | запуск игры |
| 2 | Квартира: сцена с горящей люстрой днём, HUD, Советник с репликой | начало уровня 1 |
| 3 | Карточка проблемы «Свет горит днём» с тремя вариантами действий | клик по люстре |
| 4 | Пояснение «Отличное решение!» и всплывающее «✔ +10» над объектом | выбрать «Выключить свет» |
| 5 | Мини-игра «Термостат» с шкалами комфорта и расхода тепла | клик по батарее → «Настроить термостат» |
| 6 | Колледж, столовая: мини-игра «Сортировка» с падающими предметами и 7 контейнерами | уровень 2 → вкладка «Столовая» → баки |
| 7 | Мини-город: собранная солнечная станция с анимацией потока энергии | уровень 3 → крыша → «Сложный» |
| 8 | Экран итогов: 3 звезды, % экономии, персональные советы, факт | пройти уровень |

Дополнительно: финальный экран со званием «Эксперт по энергоэффективности»; меню на белорусском языке.

## Сценарий трейлера (75 секунд)

| Время | Что на экране | Титр / текст за кадром |
|---|---|---|
| 0:00–0:05 | Главное меню, курсор нажимает «Играть» | **ЭнергоБаланс: Стратегия экономии** |
| 0:05–0:12 | Выбор уровня, экран загрузки с фактом «А ты знал?» | «Ты — энергоменеджер. Твоя задача — энергоаудит» |
| 0:12–0:25 | Квартира (демо-режим): подсветка люстры → карточка → «Выключить свет» → «+10», шкала потребления падает | «Найди, где зря тратится энергия» |
| 0:25–0:32 | Неправильный выбор «Выкрутить и читать без света» → «Не лучший выбор», комфорт падает | «Экономить — не значит отказываться от комфорта» |
| 0:32–0:40 | Мини-игра «Термостат»: ручка поворачивается, меняются шкалы | «Настрой тепло с умом» |
| 0:40–0:50 | Колледж: переключение вкладок, сортировка отходов, предмет попадает в контейнер | «Школа: свет, тепло, вода и отходы» |
| 0:50–1:02 | Мини-город: солнечная станция собрана, поток энергии к дому, ветряк на холме | «Город и чистая энергия» |
| 1:02–1:10 | Экран итогов: звёзды, проценты, советы → финал «Эксперт по энергоэффективности» | «Три уровня · три мини-игры · RU / BE» |
| 1:10–1:15 | Логотип «Энергомарафона», название игры | «Работает без интернета — просто открой index.html» |

Музыка — фоновая мелодия игры (её можно записать из самой игры). Голос за кадром — по желанию,
можно использовать реплики Советника.
